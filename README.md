# Automated-Reporting-Service
Заказчик: финансовый отдел платёжного сервиса

Бизнес-задача
Финансовый отдел каждое утро собирает сводку по операциям за предыдущий день. Операции выгружаются в CSV, курсы валют приходят из внешнего API. При повторной выгрузке в файле появляются копии операций, а при сбоях источника сотрудникам трудно определить, можно ли доверять сформированному отчёту.
